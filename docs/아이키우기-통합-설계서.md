# 아이키우기 — 통합 설계서

> 이 문서가 **유일한 스펙**이다. 이전 문서(v1, v2, 경제·소비, 접근성, 슬롯경제)는 모두 폐기한다.

---

## 0. 개요

| 항목 | 내용 |
|---|---|
| 제목 | 아이키우기 |
| 장르 | 육성 시뮬레이션 + 방치형 |
| 1차 플랫폼 | 앱인토스 (Granite / React Native) |
| 2차 플랫폼 | 구글 플레이스토어 |
| 주 타깃 | 육아 경험이 없는 20~30대 |
| 1회차 플레이 | 7~10분 |
| 예상 세션 | 4~6회, 세션당 4~5분 |

**설계 원칙: 길게 붙잡는 게 아니라 자주 돌아오게 만든다.**

## 1. 3레이어 구조

| 레이어 | 주기 | 내용 |
|---|---|---|
| 돌봄 | 실시간 | 허기·청결·기분. 탭으로 즉시 해결 |
| 육성 | 턴 (1년) | 슬롯 2칸 배분 |
| 결과 | 전체 | 계열 → 대학 → 엔딩 |

돌봄 레이어가 있어야 캐릭터 중심 화면이 성립한다. 없으면 아이는 장식이고 게임은 버튼 목록이 된다.

### 돌봄 레이어 절대 원칙

> **전부 "채우면 보너스". "안 채우면 감점"은 하나도 두지 않는다.**

- 허기가 바닥이어도 스탯은 깎이지 않는다. 아이가 계속 "배고파요"라고 말할 뿐이다
- 채우면 기분 상승 + 그 턴 성장에 소폭 보너스
- 다마고치식 방치 페널티(질병·가출 등)는 넣지 않는다

이것이 방치형과 다마고치를 동시에 굴리는 유일한 방법이다.

## 2. 진행 구조

- **1턴 = 1년**, 총 **19턴** (0세 → 19세)
- 1턴 소요: 30초~1분
- 매 턴 **슬롯 2칸** 지급
- 리워드 광고 시청 시 해당 턴 슬롯 +1

### 연령 구간

| 구간 | 나이 | 해금 |
|---|---|---|
| 유아기 | 0~5 | 기본 돌봄, 놀이 |
| 초등기 | 6~12 | 교과, 예체능, 또래 관계 |
| 중등기 | 13~15 | 심화 학습, 진로 탐색, 사춘기 이벤트 |
| 고등기 | 16~18 | 계열 확정, 입시 |
| 판정 | 19 | 엔딩 확정 |

## 3. 스탯

### 3-1. 교과 (0~100)
`국어` `영어` `수학` `과학` `사회`

### 3-2. 운동 (0~100)
`구기` `육상·수영` `무술`

### 3-3. 예술 (0~100)
`미술` `음악` `연기·무용`

### 3-4. 기질 (0~100)

| 스탯 | 역할 |
|---|---|
| `건강` | 낮으면 질병 이벤트, 성장 효율 하락 |
| `사회성` | 상경·교육 계열 가산, 삶의 질 영향 |
| `자존감` | 삶의 질 축의 주 변수 |
| `자립성` | 과잉 소비로 하락. 의존형 엔딩 판정 |
| `스트레스` | 높으면 성장 차단 |

**자존감과 자립성을 같은 방향으로 움직이면 안 된다. 갈등해야 재미있다.**

| | 자존감 | 자립성 |
|---|---|---|
| 의미 | 나를 어떻게 보는가 | 스스로 할 수 있는가 |
| 획득 | 애착, 대화, 성취 | 절제, 자율 경험 |
| 돈과의 관계 | 살 수 없음 | **쓸수록 떨어짐** |

### 3-5. 돌봄 니즈 (0~100, 실시간 감소)
`허기` `청결`

### 3-6. 자원

| 자원 | 획득 |
|---|---|
| `가계자금` | 자동 수급 + 야근 |
| `애착` | 관계 행동·요구 수용으로만 |

## 4. 계열 적합도

세부 스탯을 6계열로 집계한다. **계열마다 판정 방식이 다른 것이 핵심.**

| 계열 | 계산 | 성격 |
|---|---|---|
| 인문 | (국어 + 영어 + 사회) / 3 | 평균형 |
| 자연공학 | (수학 + 과학) / 2 | 평균형 |
| 상경 | (수학 + 사회 + 사회성) / 3 | 평균형 |
| 의약 | (과학 × 1.5 + 수학) / 2.5 | 평균형 + 높은 문턱 |
| 예술 | max(미술, 음악, 연기) × 0.7 + 평균 × 0.3 | **최고값형** |
| 체육 | max(구기, 육상, 무술) × 0.7 + 건강 × 0.3 | **최고값형** |

의약은 두 과목을 다 끌어올려야 하는 고비용 루트, 예술은 하나만 몰아도 되는 저비용 루트.
같은 편중 전략이라도 계열마다 플레이 패턴이 달라진다 → 리플레이 동기.

## 5. 슬롯 4파 경쟁

매 턴 슬롯 2칸을 놓고 넷이 경쟁한다.

| 용도 | 얻는 것 | 잃는 것 |
|---|---|---|
| 요구 수용 | 애착 ++, 수용 보너스 | 자금, 자립성 |
| 육성 | 해당 스탯 | 스트레스, 자금 |
| 돌봄 | 니즈 충족, 성장 보너스 | 스탯 성장 기회 |
| 야근 | 골드 대량 | 애착, 그 턴 아이에게 아무것도 못 함 |

**요구는 강제가 아니다.** 배고프다고 해도 무시하고 학원을 보낼 수 있어야 선택이 된다.

### 부재와 거절의 분리 — 핵심 원칙

| | 정의 | 결과 |
|---|---|---|
| 부재 | 앱을 끄고 안 들어옴 | **아무 페널티 없음.** 요구는 그대로 대기 |
| 거절 | 화면에서 요구를 보고 다른 걸 선택 | 애착 −, 자립성 + |

- 요구에 **실시간 타이머를 걸지 않는다.** 기한은 "다음 턴 넘기기 전까지"
- 며칠 뒤에 들어와도 요구는 그대로 있고 보너스도 유효하다
- 능동적 선택에만 결과가 따른다

## 6. 경제

### 6-1. 자동 수급

| 항목 | 값 |
|---|---|
| 수급 간격 | 1초 |
| 오프라인 누적 상한 | 12시간치 |
| 부재 페널티 | **없음** |

상한 도달 시 누적 정지 → 재방문 동기는 손해 회피가 아니라 자원 회수.

### 6-2. 수급 업그레이드

| 업그레이드 | 효과 | 비용 곡선 |
|---|---|---|
| 부업 | 초당 수급 +flat | 완만 |
| 승진 | 초당 수급 ×배율 | 중간 |
| 투자 | 초당 수급 ×배율 | 가파름 |
| 부동산 | 초당 수급 ×배율 | 매우 가파름 |
| 누적 상한 확장 | 12h → 24h → 48h | 계단식 |

`cost = base × growth^level`. 상위는 하위 레벨로 해금.

**초반엔 업그레이드와 소비가 실제로 경쟁하고, 후반엔 여유가 생긴다.**
→ 재화의 제약이 초반 총량에서 후반 적정선으로 자연스럽게 이동한다.

### 6-3. 야근

| 항목 | 값 |
|---|---|
| 슬롯 소모 | 1 |
| 획득 | 자동 수급 N시간치 상당 |
| 대가 | 애착 −, 그 턴 육성·돌봄 기회 상실 |
| 요구 중이면 | 거절로 처리 (애착 추가 감소, 자립성 +) |

연속 야근 페널티: 2회 애착 감소 1.5배, 3회 이상 2배 + 아이 대사 부정 고정.

**야근을 한 번도 안 해도 게임이 진행돼야 한다.** 필수가 되면 "아이를 방치해야 이기는 게임"이 된다.

### 6-4. 소비 — 역U자 곡선

```
적정선 미만 → 자존감 ↓, 사회성 ↓   (또래 사이 위축)
적정선      → 소폭 긍정
적정선 초과 → 자립성 ↓             (부모 의존)
```

**돈이 무한해도 최적 구간을 넘기면 손해다.** 방치형 무한 수급과 의미 있는 선택을 양립시키는 장치.

| 카테고리 | T1 | T2 | T3 | T4 |
|---|---|---|---|---|
| 음식 | 집밥·간편식 | 배달·외식 | 뷔페·좋은 식당 | 오마카세 |
| 의상 | 보세·물려받기 | SPA | 중가 브랜드 | 명품 |
| 집 | 원룸·빌라 | 소형 아파트 | 중형 아파트 | 고급 주택 |
| 여행 | 근교 당일 | 국내 숙박 | 해외 근거리 | 해외 장거리 |

| 카테고리 | 방식 | 슬롯 | 비용 |
|---|---|---|---|
| 음식·의상·집 | 지속 설정 | 소모 안 함 | 매 턴 유지비 |
| 여행 | 단발 행동 | **1 소모** | 일시불 |

의식주는 슬롯을 쓰지 않아 턴이 복잡해지지 않고, 여행만 슬롯을 써서 "학원 대신 여행"이 성립한다.

| 카테고리 | 적정 시 효과 |
|---|---|
| 음식 | 건강 +, 스트레스 − |
| 의상 | 사회성 +, 자존감 + |
| 집 | 스트레스 −, 학습 효율 + |
| 여행 | 애착 ++, 스트레스 −−, 감성 + |

**적정선은 나이에 따라 이동한다.**

| 시기 | 적정 티어 | 특징 |
|---|---|---|
| 유아기 | T1 | 과잉 페널티 최대. 명품·해외여행은 대부분 낭비 |
| 초등기 | T1~T2 | 균형 |
| 중등기 | T2~T3 | 또래 비교 시작, 결핍 페널티 증가 |
| 고등기 | T2~T3 | 결핍 페널티 최대 |

고정하면 한 번 맞춰놓고 잊는다. 이동시켜야 지속적 재조정이 된다.

**여행 특칙**: 3턴 이상 없으면 스트레스 누적 가속. 매 턴 여행하면 애착 획득 급감 + 자립성 하락. T4 장기여행은 교과 정체.

## 10. 요구 이벤트

티어 설정만으로는 스프레드시트에 그친다. **아이가 직접 조르면 같은 수치가 감정적 선택이 된다.**

```
[요구 텍스트]
  들어준다 → 애착 +, 자립성 −, 자금 −
  거절한다 → 애착 −, 자존감 − (소폭), 자립성 +
```

| 시기 | 요구 | 들어줌 | 거절 |
|---|---|---|---|
| 유아 | 장난감 | 애착 +6, 자립성 −4 | 애착 −3, 자립성 +5 |
| 초등 | 친구들 다 있는 게임기 | 애착 +8, 사회성 +4, 자립성 −6 | 애착 −5, 사회성 −3, 자립성 +8 |
| 중등 | 친구들 신는 신발 | 애착 +8, 자립성 −6 | 애착 −5, 자존감 −3, 자립성 +8 |
| 중등 | 학원 그만두고 싶다 | 스트레스 −15, 과목 정체 | 스트레스 +10, 자존감 −5 |
| 고등 | 친구들과 해외여행 | 애착 +10, 사회성 +8, 자립성 −8, 자금 −− | 애착 −8, 사회성 −5, 자립성 +10 |

**밸런스 원칙**
- 전체 이벤트의 약 30%를 요구 이벤트로
- 자금이 충분해도 들어주는 게 항상 정답이면 안 된다
- 자립성이 낮으면 요구 빈도 증가 (악순환)
- 자립성이 높으면 아이가 스스로 포기하는 서술 (보상감)

## 11. 엔딩

`대학 티어(5) × 학과 계열(6) × 삶의 질(3) = 90가지`
텍스트는 축별 조각 조합이므로 실제 작성량은 14덩어리.

### 축 1 — 대학 티어

| 티어 | 조건 |
|---|---|
| 최상위권 | 계열 적합도 85+ & 교과 평균 80+ |
| 상위권 | 계열 적합도 70+ |
| 중위권 | 계열 적합도 55+ |
| 전문대·특성화 | 계열 적합도 40+ |
| 비진학 | 그 외 |

### 축 2 — 학과 계열

최고 계열 적합도가 곧 학과. 최고값과 차순위 차이가 10 미만이면 자유전공·복수전공.

### 축 3 — 삶의 질 (대학 티어와 완전히 독립)

| 결말 | 조건 |
|---|---|
| 굿 | 자존감 70+ & 애착 60+ & 자립성 55+ |
| 노멀 | 그 중간 |
| 배드 (관계형) | 자존감 35− 또는 (자존감 50− & 애착 30−) |
| 배드 (의존형) | 자립성 30− |

### 반드시 지킬 것

- **대학 티어가 삶의 질을 결정하지 않는다.**
- 최상위권 의대 + 배드엔딩, 비진학 + 굿엔딩이 모두 성립해야 한다
- 성립하지 않으면 이 게임은 "좋은 대학 = 좋은 인생"을 말하는 게임이 된다

### 톤 가이드

- 비진학·전문대 엔딩을 실패로 묘사하지 않는다
- 배드엔딩은 아이를 비난하지 않는다. 원인을 선택의 누적에 둔다
- 자해·정신질환을 소재로 삼지 않는다
- 애착이 높으면 회복 여지를 남긴다
- 의존형 배드엔딩은 학벌 자체는 문제없었음을 명시하고, 스스로 결정해본 경험 부족으로 서술한다

> 이 엔딩이 있어야 "다 해주는 것"이 사랑이 아니라는 게 게임 안에서 증명된다.

### 텍스트 구조

```
[대학 티어] + [학과 계열] + [삶의 질 문단]

"수도권 상위권 대학의 시각디자인과에 입학했다."
"학과 사람들과 잘 어울렸고, 3학년 때 낸 포트폴리오가 좋은 평을 받았다.
 졸업 후에는 작은 스튜디오에 들어가 자기 이름으로 일을 받기 시작했다."
```

엔딩 화면에는 왜 이 엔딩이 나왔는지 한 줄로 설명하고, 다음 회차 힌트 1개를 제공한다.

## 12. UI

### 화면 구성

```
나이 · 계절 · 자금
말풍선 (요구 또는 상태 대사)
아이 캐릭터 (중앙, 전신)
돌봄 니즈 (허기 · 기분 · 청결)
하단 메뉴 (밥 · 옷장 · 대화 · 일정)
```

세로 고정. 스크롤 없이 한 화면.

### 지표 노출 원칙

- **숫자를 노출하지 않는다.** 등급으로 표기 ("스트레스 62" → "지침")
- 세부 스탯 15종과 계열 6종은 뒤에서 돌아가되 탭해야 보인다
- 자립성·자존감은 기본 화면에 없다. 아이 대사로만 드러난다

### 선택지 결과 미리보기

```
수학학원        수학 ▲ · 기분 ▼
같이 놀아주기    사이 ▲ · 기분 ▲
```

방향만 표시하고 수치는 감춘다. 큰 변화는 ▲▲. 최대 2~3개 항목만.

**뭘 잃는지 알면서 고르는 게 트레이드오프다. 모르고 고르는 건 운이고, 운은 재미가 없다.**

### 겉 표시와 속 계산의 일치

등급 경계값과 엔딩 판정 문턱은 **같은 상수 파일에서 관리한다.**
"잘함"이라고 떴는데 원하는 대학을 못 가면 유저는 배신감을 느낀다.

## 13. 상태 대사

스탯 구간에 대사를 매핑한다. 복잡한 로직은 필요 없다.

- 나이대(유아/아동/청소년)별로 말투가 달라야 한다
- 구간별 3~5개 준비해 랜덤 출력, 연속 반복 회피
- 한 턴에 하나만 노출
- 요구 이벤트가 있으면 그것이 우선
- 일부 대사는 상태를 직접 말하지 않고 비껴가게 둔다
  (소비 결핍 청소년: 조르는 대신 "…아니에요. 괜찮아요.")

구현: `src/core/data/dialogue.ts` 참조.

## 14. 아트 디렉션

### 구조 (사용 가능 — 장르 관습)

- 캐릭터가 중앙에 전신, 배경이 장소를 표현
- 의상 레이어 합성 (갈아입히면 스프라이트 반영)
- 나이대별 스프라이트 교체
- 이벤트 컷인 일러스트

### 금지

- 기존 게임의 캐릭터 디자인을 그대로 옮기는 것
- 에셋 추출·트레이싱
- AI 생성 시 프롬프트에 특정 게임 이름을 넣는 것 (원작 근접 위험). 스타일 속성으로 풀어 쓸 것

### 화풍

현대 한국 배경이므로 90년대 판타지 셀화풍은 톤이 맞지 않는다.

- 현대 한국 웹툰풍 라인 아트, 또는
- 플랫한 캐주얼 일러스트 (토스 앱 톤과 일관 — 검수·UI 일관성 유리)

### 용량

```
베이스 몸 (나이대 4~5종) + 상의 파츠 + 하의 파츠 + 표정 파츠
→ 런타임 레이어 합성
```

나이대는 4~5단계면 충분. 배경은 장소별 1장, 재사용.

- 매 턴 종료 시 자동 저장

## 18. 밸런싱 체크리스트

이 항목들이 전부 통과해야 설계가 성공한 것이다.

- [ ] **요구를 전부 들어준 플레이와 전부 거절한 플레이가 둘 다 배드엔딩인가**
- [ ] 매 턴 야근만 하는 플레이가 배드엔딩으로 가는가
- [ ] 야근을 한 번도 안 해도 게임이 완주되는가
- [ ] 모든 티어를 T4로 유지하면 자립성 배드엔딩으로 가는가
- [ ] 유아기에 T4를 유지하면 확실히 손해인가
- [ ] 고등기에 T1을 유지하면 확실히 손해인가
- [ ] 최상위권 대학 + 배드엔딩이 실제로 나오는가
- [ ] 비진학 + 굿엔딩이 실제로 나오는가
- [ ] 6계열 엔딩에 모두 도달 가능한가
- [ ] 화면 등급 표시와 엔딩 판정 결과가 어긋나지 않는가
